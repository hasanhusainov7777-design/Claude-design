# Karusel

Простая карусель (слайдер) на чистом HTML, CSS и JavaScript без зависимостей.

- кнопки «назад» и «вперёд», точки-индикаторы
- свайп мышью или пальцем, стрелки на клавиатуре
- автопрокрутка каждые 5 секунд

Чтобы запустить, откройте `index.html` в браузере.
Чтобы добавить слайд, добавьте ещё один `<div class="slide">` в `.track`.
